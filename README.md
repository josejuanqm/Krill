# Krill

A native Portainer client for iOS, macOS, and Android.

Krill gives you full control over your Portainer-managed infrastructure from your phone or desktop. Monitor environments, manage containers and stacks, and switch between multiple servers -- all from a fast, native interface.

**Status: Beta 1**

## Features

- **Dashboard** -- Overview of environments, containers, images, volumes, and stacks at a glance
- **Environments** -- Browse all Docker and Kubernetes endpoints with live status indicators
- **Containers** -- View details, logs, stats (CPU/memory charts), environment variables, labels, mounts, and network config. Start, stop, restart, kill, or remove containers.
- **Stacks** -- List, inspect, start, and stop Compose and Swarm stacks
- **Multi-server** -- Add multiple Portainer instances and switch between them from the title dropdown
- **User management** -- List users, create users, manage teams, change passwords, generate API keys (admin)
- **Registries** -- View and add Docker registries
- **Settings** -- Configure Portainer instance settings, Kubernetes options, and session timeouts (admin)
- **Pull to refresh** -- Native pull-to-refresh on all data screens
- **Dark and light mode** -- Follows system appearance

## Getting Started

1. Install Krill on your device
2. Enter your Portainer server URL (e.g. `https://portainer.example.com`)
3. Log in with your Portainer credentials
4. You're in -- your dashboard loads automatically

To add more servers, tap the title in the dashboard and select **Add Server**.
